# Hızlı Top

Tr1Action'ın kişisel kullanım için Türkçeleştirdiği [QuickBall](https://github.com/chayanforyou/QuickBall) sürümü.

Ekranda tüm uygulamaların üstünde duran yüzen bir top: dokununca ses, parlaklık, fener, Wi-Fi, Bluetooth, ekran görüntüsü, ekran kilidi, müzik kontrolleri gibi kısayollar yelpaze şeklinde açılır.

## Bu sürümde farklı olanlar

- Varsayılan dil Türkçe (uygulama içinden diğer dillere geçilebilir)
- Kendi paket adı: `io.github.tr1action.quickball` (orijinal uygulamayla birlikte kurulabilir)
- Bağış / puanlama pencereleri kaldırıldı
- Her `master` güncellemesinde GitHub Actions APK derleyip **Releases** kısmına koyar

## Kurulum

[Releases](https://github.com/Tr1Action/quickball/releases/latest) sayfasından `HizliTop.apk` dosyasını indirip kur, sonra uygulamada Erişilebilirlik ve Sistem Ayarları izinlerini ver.
